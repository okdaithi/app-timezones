# Perth ⇄ Galway

An Android home-screen widget showing the time in Perth and Galway, and when a call suits both cities.

## Download

**[⬇ Download the latest app (APK)](https://github.com/okdaithi/app-timezones/releases/latest/download/dual-clock.apk)**

Requires Android 8.0 or later.

> The download link starts working when the first release (v1.0.0) is published. Until then, see [other ways to get the app](dual-clock/INSTALL.md#1-get-the-apk).

## Install

1. On the phone, tap the download link above.
2. Open the downloaded file. When Android asks, allow installs from this source, then tap **Install**.
3. If Google Play Protect warns about an unknown app, tap **More details → Install anyway**. The app isn't on Google Play, which is why the warning appears.
4. Open **Perth ⇄ Galway** once. This lets the widget keep updating after the phone restarts.
5. Long-press an empty spot on the home screen, tap **Widgets**, find **Perth ⇄ Galway**, and drag it onto the home screen.

## Updates

Pick one:
- **Automatic:** install [Obtainium](https://github.com/ImranR98/Obtainium), tap **Add App**, and paste `https://github.com/okdaithi/app-timezones`. Obtainium tells you when there's a new version and installs it.
- **Manual:** download from the link above again and tap **Update**.

Updating keeps your settings and the widget on your home screen.

> **Installed a test build before v1.0.0?** Uninstall it once, then install the release. Test builds were signed with a different key, so Android won't update them in place.
